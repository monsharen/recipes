# Welcome
This is a personal recipe site without the bloat, that promotes careful curation and content improvement over time. The engine compiles recipe files into static html pages which can be hosted on gitlab or github pages.

With pipeline definitions the entire page is recompiled and deploy on commit.

# Build steps
1. Add recipe files in the recipes folder
2. Compile to regenerate the static recipe html pages

Live demo: http://monsharen.gitlab.io/recipes
